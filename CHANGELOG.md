## [0.1.0-beta.1] - 2026-08-16

### Added

- Official DSH theme, session and Slot integration.
- Seven-state semantic Agent state engine.
- Status, composer, tool, approval/blocked and completion surfaces.
- Native settings, local wallpaper presets/import, contrast compensation and
  Eco/Balanced/Cinematic quality tiers.
- Reduced-motion/transparency fallbacks, privacy-safe diagnostics and clean
  enable/disable/uninstall lifecycle.
- Automated contract/state/config/material tests and isolated-profile browser
  acceptance evidence.

### Security

- No plugin network requests, telemetry, credentials, filesystem or shell
  access.
- No proprietary Apple/DeepSeek assets or source patches.

Comparison links will be added when the public repository URL is known; no
placeholder URL is shipped as an install instruction.
